# FinAI — система учёта для малого бизнеса

Дипломный проект. Программное обеспечение для бухгалтерского и складского учёта индивидуальных предпринимателей и малых предприятий с использованием машинного обучения. Система ведёт двойную бухгалтерскую запись, автоматически классифицирует операции по категориям на основе ML-модели, поддерживает импорт банковских выписок, складской учёт и прогнозирование денежных потоков и товарных остатков.

## Состав проекта

- `backend.py` — серверная часть на FastAPI. Содержит всю бизнес-логику: операции и двойную запись, складской учёт, импорт выписок, ML-предсказания, прогнозы.
- `frontend.py` — пользовательский интерфейс на Streamlit. Шесть вкладок: дашборд, список операций, импорт выписки, склад, прогноз денег, прогноз товаров.
- `generate_data.py` — генератор синтетического набора данных для обучения модели (20 000 записей).
- `train_model.py` — скрипт обучения классификатора XGBoost.
- `model.pkl`, `vectorizer.pkl`, `label_encoder.pkl` — обученная модель и сопутствующие объекты. Присутствуют в репозитории, повторное обучение не требуется.
- `finai.db` — база данных SQLite.
- `synthetic_transactions.csv` — обучающий датасет.

## Требования к окружению

Рекомендуется Python 3.10. Более новые версии (3.11, 3.12) в большинстве случаев также работоспособны, однако на Python 3.13 установка numpy и pandas может завершиться ошибкой сборки из-за отсутствия готовых wheel-пакетов.

## Порядок запуска

Клонировать репозиторий и перейти в его директорию:

    git clone https://github.com/nicko587/FinAI.git
    cd FinAI

Создать и активировать виртуальное окружение (Windows):

    py -3.10 -m venv venv
    venv\Scripts\activate

При работе в PowerShell возможны ограничения политики выполнения скриптов. В этом случае следует переключиться на вкладку Command Prompt (доступна в терминале PyCharm через значок «+»).

Установить зависимости:

    pip install -r requirements.txt

Если файл `requirements.txt` отсутствует, создать его со следующим содержимым:

    fastapi
    uvicorn
    streamlit
    sqlalchemy
    pydantic
    pydantic-settings
    python-dotenv
    numpy
    pandas
    scikit-learn
    xgboost
    python-multipart
    openpyxl
    plotly
    statsmodels

Запуск выполняется в двух терминалах. В первом:

    python backend.py

Дождаться сообщения `Uvicorn running on http://127.0.0.1:8000`. Во втором терминале:

    streamlit run frontend.py

Интерфейс доступен по адресу http://127.0.0.1:8501.

## База данных и модель

Файл `finai.db` и объекты модели (`model.pkl`, `vectorizer.pkl`, `label_encoder.pkl`) включены в репозиторий, поэтому при первом запуске обучение не требуется. При необходимости полной пересборки удалить базу данных и выполнить:

    python generate_data.py
    python train_model.py

После этого запустить `python backend.py` — таблицы будут созданы автоматически.

## Проверка работоспособности

Рекомендуется следующий сценарий. Во вкладке «Склад» добавить товар (например, «Молоток») с закупочной ценой 150 рублей. Выполнить приход на 10 единиц — в списке операций появится расходная операция на сумму 1500 рублей. Затем продать 3 единицы по цене 300 рублей — система создаст две записи: доход 900 рублей и себестоимость продажи 450 рублей. Итоговые показатели на дашборде должны быть согласованы.

Для проверки импорта подготовить CSV-файл с колонками «Дата операции», «Описание», «Сумма» (формат Тинькофф) либо с аналогичными по смыслу названиями. Система автоматически определяет разделитель и сопоставляет колонки.

## Текущие ограничения

Аутентификация не реализована, идентификатор пользователя зафиксирован как 1. Экспорт отчётов в форматы, принимаемые налоговыми органами, не выполнен. Интеграция с Telegram и распознавание чеков через OCR заявлены в спецификации требований, но в текущей версии отсутствуют. Указанные функции отнесены к направлениям дальнейшего развития.

## Используемые технологии

FastAPI, SQLAlchemy, SQLite, Streamlit, XGBoost в связке с TF-IDF, statsmodels (экспоненциальное сглаживание для прогнозов), Plotly.
